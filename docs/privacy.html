Privacy Policy

Alienizer Browser Extension

This extension does not collect, store, transmit, or share any personal or sensitive user data.

The only data stored is user preferences (intensity settings, preset selection, auto-activation toggle) using chrome.storage.sync, which remains on the user's device and syncs only through the user's own Chrome profile.

No analytics, tracking, or third-party services are used.
